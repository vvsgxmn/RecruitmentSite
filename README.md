# 基于SpringBoot+Vue的招聘网站系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

RecruitmentSite 是一款面向求职者、企业 HR 与平台管理员的在线招聘网站，支持职位大厅多维筛选、在线简历、投递与面试邀约、人才库搜寻、企业资质认证、职位合规审核、职场资讯与运营驾驶舱，并接入通义千问完成简历润色、人岗匹配与模拟面试，适合毕设、课设与学习参考。

## 主要功能模块

- **用户认证模块**：支持求职者、企业HR、管理员三类角色注册登录，JWT 鉴权并按角色进入门户/招聘台/管理中台
- **求职门户模块**：首页轮播、职位大厅筛选、名企专区、职位收藏投递、投递进度与面试通知
- **在线简历模块**：结构化简历维护、附件上传、人才库公开开关与简历快照投递
- **企业招聘台模块**：招聘看板、职位发布管理、投递简历筛选推进、面试邀约与人才库搜寻
- **AI求职副驾**：通义千问驱动的简历润色、人岗匹配评测与模拟面试
- **后台运营模块**：数据驾驶舱、职位合规审核、企业资质认证、分类用户资讯与轮播维护

## 技术架构

- **后端**：Spring Boot + MyBatis-Plus + JWT + Lombok
- **前端**：Vue + Vue Router + Pinia + Element Plus + Vite + ECharts
- **数据库**：MySQL
